# AI Website Builder

An AI-powered website builder that generates and updates responsive websites using natural language prompts.

## Features

- AI-based website generation
- Edit websites using natural language prompts
- Responsive UI
- Live website preview
- User authentication
- Project management
- REST API integration

## Tech Stack

- React.js / Next.js
- Node.js
- Express.js
- MongoDB
- Tailwind CSS
- AI API

## Getting Started

### Clone the repository

git clone YOUR_GITHUB_LINK

### Install dependencies

npm install

### Run the project

npm run dev
